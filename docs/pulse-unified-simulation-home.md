# Simulation 홈 통합 (2026-10-14)

사용자 실제 화면 요청으로 실행 도구 카드와 테스트 목록 카드를 하나로 합쳤다. 프로젝트명/테스트 수/새로고침, 작은 자동 추적 상태, 실행 버튼·오른쪽 이력/TB 파일/TB 폴더, 구분선과 TB 목록 순서다. 중복 테스트 제목/개수 표시는 제거하고 기존 실행/등록/신뢰/복원 provider 행동은 유지한다. 정상 신뢰 프로젝트의 반복적인 보관 입력 설명은 숨기며, 신뢰/보관 전용 경고와 변경 알림은 유지한다.

Simulation 설정은 페이지 제목 높이의 오른쪽 icon으로 이동했다. 아이콘 내부를 상태 문구로 덮어쓰지 않고 tooltip으로 복구 필요 상태를 표시한다. 시작 화면에서는 설정 아이콘을 숨긴다.

정상 Simulation 페이지는 편집기 작업 영역 높이를 사용한다. 합친 카드가 남은 공간을 채우고 TB 목록 내부가 스크롤한다. 실행 로그는 기본 접힘/아래 배치다. 펼치면 위쪽으로120~300px(화면 약30%)을 차지하고 목록 높이가 줄어든다. 매우 작은 영역에서는 최소 높이와 외부 스크롤로 조작 항목이 잘리지 않게 한다. 시작 화면·프로젝트 준비·내장 파형에는 이 페이지 높이 정책을 적용하지 않는다. VS Code 공통 하단 Terminal/Output은 변경하지 않는다.

검증: 실제 Home/provider·최근/설정/복원 관련26 PASS/0 FAIL, 전체 본체 타입/owned emission0 errors. 로그 `ide/.dev/windows-integrated/pulse-unified-home-tests.log`, `pulse-unified-home-types.log`. 타입화된 설정 icon 및 기존 복구 이름 검사를 tooltip 계약으로 변경했다. 이전38개 검사와 합산하지 않는다. 화면/실제 CSS 크기·로그 확장/긴 목록/좁은 창은 이번 작업에서 검증하지 않았다. Computer Use 새 승인이 필요하며 Setup 미변경.

최신 개발 본체를 compile하고 latest-launch prepare를 갱신했다. 사용자는 ide/Start-Pulse.cmd를 다시 실행해 확인할 수 있다. 다음은 사용자 피드백 또는 한 번의 승인된 화면 수용이며, 배포는 사용자가 괜찮다고 판단한 뒤 진행한다.
