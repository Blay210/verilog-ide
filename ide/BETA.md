# Pulse 내부 베타 안내

Windows x64 스터디 내부 테스트용입니다. 정식 안정판이나 공개 배포판은 아닙니다. 이 안내가 존재한다는 것만으로 배포 빌드·설치 검증이 끝났다는 뜻은 아닙니다.

2026-10-14 후보는 기존 Windows 환경에서 전체 회귀340 PASS/1 POSIX SKIP, 이후 초기 복원·무결성 관련23 PASS와 공식 전체 타입 검사를 통과했습니다. 검증용 extension 없는 일반 앱의 보관 소스 자동 복원→실제 테스트 PASS→내장 파형/커서 정렬→작업 공간 왕복→정상 닫기도 확인했습니다. 압축 파일별 읽기/해시 확인 결과는 ZIP 안의 수용 기록과 함께 제공되는 manifest에 기록됩니다. 깨끗한 새 PC 설치 수용과는 구분합니다.

## 처음 사용하기

설치판을 받았다면 `Pulse-Setup-windows-x64-beta-20261014.exe`를 실행합니다. 사용자 계정에 설치하고 시작 메뉴에 Pulse를 등록하며, 바탕화면 바로가기는 선택할 수 있습니다. 아래 ZIP 방식도 계속 지원합니다. [설치·제거 동작 및 검증 범위](../docs/pulse-windows-installer.md)를 참고하세요.

1. 배포 ZIP을 쓰기 가능한 폴더에 풀고 `Pulse.exe`를 엽니다. 개발용 Node/npm이나 이 저장소는 필요하지 않습니다. 앱 설정은 사용자 프로필에 보관됩니다.
2. Code에서 RTL 프로젝트 폴더를 엽니다. 기존 폴더 구조와 소스는 그대로 유지됩니다.
3. Simulation으로 이동합니다. 기존 설정이 없으면 탐색 결과를 검토하고 테스트를 등록합니다. TB 폴더를 등록하면 파일 추가·삭제와 한 파일의 여러 module이 목록에 반영됩니다. 자동으로 실행되지는 않습니다.
4. 도구가 없으면 도구 설정에서 필요한 도구와 설치 위치를 확인한 뒤 승인합니다. 기존 도구가 있으면 먼저 재사용 여부를 확인합니다. 시스템 PATH를 직접 설정하는 흐름을 기본으로 삼지 않습니다.
5. 행의 실행 버튼, 선택 실행 또는 전체 실행을 누릅니다. 완료 후 로그·파형 버튼으로 결과를 확인합니다. 실행 완료 때문에 화면이 강제로 바뀌지 않습니다.

미저장 RTL 편집 내용은 실행 시작 시점 복사본으로 사용하며 원본을 자동 저장하지 않습니다. 설정 파일의 미저장 변경은 먼저 정리해야 합니다. TB에 dump 코드를 작성하거나 C++ harness를 만들 필요가 없습니다.

## 파형과 이전 결과

Signals에서 신호를 고르고 행을 드래그해 순서를 바꿉니다. bus는 비트별로 펼칠 수 있습니다. Cursor/Zoom range로 마우스 동작을 선택합니다. 시간은 절대시간이며 긴 값은 나누어 표시합니다.

Save view로 테스트별 여러 보기를 저장하고 Use as default로 기본 구성을 지정할 수 있습니다. 이전 실행 파형은 새 결과와 별도로 유지됩니다. 이력에서 이전 결과를 선택하고 보관 소스·입력 비교·소스 차이로 당시 코드와 현재 코드를 구분합니다. PASS/FAIL과 현재 코드가 변경됐다는 표시는 서로 다른 상태입니다.

## 현재 지원 범위와 알려진 제한

- Windows x64, Verilator 실행, 내장 VCD 보기. FST 생성은 가능하지만 내장 FST 표시와 RTL enum 이름 매핑은 아직 연결되지 않았습니다.
- Code/Simulation, 내장 RTL 편집 기능, 테스트 관리·취소·로그·이력·보관 소스. 외부 extension 설치/Marketplace·Chat·Diagram·자체 compiler/simulator는 첫 앱 범위에 없습니다.
- 개발 앱에서 시작 지연과 extension host 경고를 관찰했습니다. 배포 앱의 시작 시간과 장시간 메모리는 별도 측정해야 합니다.
- 별도 깨끗한 Windows PC/VM이 없어 신규 설치 전체 흐름은 아직 검증하지 못했습니다. DPI/고대비·대표 실제 대형 설계 등 추가 수용도 남아 있습니다.
- 프로젝트 생성물은 `.rtl/`, TB 선택은 `rtl-tests.json`에 저장됩니다. 중요한 소스·설정은 Git에 보관하세요. 기존 결과 정리의 전체 디스크 정책은 아직 확정되지 않았습니다.

## 피드백

문제가 생기면 앱 버전/배포 파일 이름, 어떤 버튼을 눌렀는지, 실행 로그와 재현 가능한 최소 RTL을 함께 알려주세요. 비밀 값이나 공유하면 안 되는 설계는 로그·소스에서 제거한 뒤 전달하세요. 파형 사용성·자동완성·Simulation 목록에서 불편한 점도 기록해 주세요.

## 파형 탭 (2026-10-14)

홈은 집 아이콘, 파형 탭은 테스트 이름과 내부 ×로 표시됩니다. 같은 테스트의 여러 실행은 툴팁의 시각·ID로 구분합니다. 비활성 탭을 닫아도 현재 파형은 유지됩니다.

## 배포 파일 확인

ZIP과 함께 제공되는 `.sha256` 파일은 배포 파일의 무결성을 확인하는 값입니다. ZIP 안의 `PULSE-NOTICES.txt`와 기존 Code-OSS/Chromium 고지를 보존해 주세요. 앱의 1.141.0 표시는 기반 Code-OSS 버전이며 이번 배포는 날짜가 붙은 Pulse 내부 베타입니다.

Verilator·C++ 빌드 도구와 slang/Python은 앱 ZIP에 포함되지 않습니다. 처음 설치할 때는 다운로드와 사용자의 설치 승인이 필요하며, 이미 있는 도구는 검증 후 재사용합니다. 앱 실행 자체에 저장소 checkout이나 개발용 Node는 필요하지 않습니다. 도구를 설치하지 않아도 코드 편집은 가능합니다.
