# Pulse 베타 제공 범위

이 문서는 2026-10-16 Pulse (beta)의 제품 범위입니다. 기존 2026-10-14 Setup/ZIP과 구분하며 실제 검사·미검증 범위는 동봉된 수용 기록과 새 Setup manifest에 표시합니다.

- Code와 Simulation을 작업 공간으로 사용합니다. Explorer/Search/Git과 하단 terminal/output은 유지합니다. RTL 실행은 Simulation 또는 등록된 TB의 Run/F5를 사용합니다. 일반 host Debug/Testing은 RTL 시뮬레이션과 다르며 별도 사이드바 진입을 제공하지 않습니다.
- 새 프로젝트는 빈 rtl/tb와 IDE 관리 설정을 준비합니다. Counter 예제·검증 프로젝트는 제품 생성 기능이 아닙니다. 기존 프로젝트는 원본을 유지하고 프로젝트 준비로 가져옵니다. 기본 폴더 역할·TB 후보를 제안하고, 필요한 경우 프로젝트 설정에서 분류/include/defines를 조정합니다.
- IDE 관리 문서만 저장된 폴더 역할과 사용자의 명시적 제외·추가를 기준으로 소스/TB 목록을 추적합니다. 일반 TOML 또는 사용자가 직접 수정한 TOML을 자동 관리 대상으로 강제 전환하지 않습니다. 목록 변화로 compile/run하지 않습니다. 한 파일의 서로 다른 complete top은 별도 테스트입니다.
- Verilator timing/assert와 자동 파형 기록을 사용합니다. 원본 dump 코드·C++ harness는 필요하지 않습니다. 실패는 assertion/$fatal로 표현합니다. VCD는 내장 viewer, FST는 명시적으로 GTKWave를 엽니다. 일반 VCD 파일도 열 수 있으나 실행 이력·보관 소스와 연결된 파형은 아닙니다.
- 테스트별 저장 신호 보기, 실행 시점 소스·이력, 최근 최대1,000개 명시적 이력 조회를 지원합니다. 이력 파일이나 소스를 자동 삭제하지 않습니다. `.rtl/`을 삭제하면 실행 기록/파형/보관 소스가 없어지므로 필요한 결과를 먼저 보존하세요.
- 내장 reader는 최대4개, trace 최대32MiB/신호10,000개/변화1,000,000개/선택32개/펼친 bit row128개 한도입니다. 큰 trace는 GTKWave로 여는 선택을 제공합니다. 기록 파형의 외부 열기는 최대128MiB를 메모리에 통째로 보관하지 않고 hash/보관 입력을 검증합니다.
- 첫 가져오기에서 한 번에 의미 분석하는 top은 최대32개입니다. 복잡한 혼합 package/module 파일·macro/include 구성은 수동 설정이 필요할 수 있습니다. IDE 관리 설정의 삭제된 추가 include 폴더는 자동으로 지우지 않으며 필요한 설정을 검토해야 합니다.
- 실행 중 Code/Simulation 전환 상태는 유지하지만 프로젝트·앱 종료 후 마지막 Pulse 공간/파형 탭/커서를 자동 복원하지 않습니다. 최근 프로젝트·실행 이력·보관 소스/파형·미저장 편집기 복구는 보존합니다. 없어졌거나 변조된 결과를 자동 재생성하지 않으며, 일반 VCD는 실행 snapshot으로 취급하지 않습니다. 도구 설치·외부 viewer·시뮬레이션을 시작 과정에서 자동 실행하지 않습니다.
- Diagram, synthesis, 자체 compiler/simulator와 외부 확장 설치는 이번 베타 제공 범위가 아닙니다. 개발용 DOM 상태·강제 클릭 명령/계측 로그·검증 fixture는 배포 앱에서 제외합니다. 실제 실행/설정·언어 및 도구 오류 확인 기능은 유지합니다. vsix와 ide는 독립 source/dependency/build 경계를 유지합니다.

깨끗한 Windows PC/VM 설치, DPI/실제 중간 규모 설계 및 장시간 메모리 수용은 기존 제한과 마지막 검증 결과를 별도로 확인하세요. 이전 테스트 결과만으로 이번 보완을 수용 완료로 선언하지 않습니다.
